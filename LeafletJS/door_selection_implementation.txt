# Implementation Instructions for findClosestDoor Feature

## Step 1: Add findClosestDoor function

Insert this function BEFORE the `findPathToObject` function (around line 1100):

```javascript
        // Find the closest door to the user's position
        function findClosestDoor(doorList, svgMap, overlay, userPosition) {
            if (!doorList || doorList.length === 0) return null;
            if (doorList.length === 1) return doorList[0];
            
            let closestDoor = null;
            let minDistance = Infinity;
            
            doorList.forEach(doorId => {
                const doorElement = svgMap.getElementById(doorId);
                if (doorElement) {
                    try {
                        const doorCenter = objectToLatLng(doorElement, svgMap, overlay);
                        const distance = userPosition.distanceTo(doorCenter);
                        
                        console.log(`📏 Door ${doorId} distance: ${distance.toFixed(2)}m`);
                        
                        if (distance < minDistance) {
                            minDistance = distance;
                            closestDoor = doorId;
                        }
                    } catch (error) {
                        console.warn(`⚠️ Could not calculate position for door ${doorId}:`, error);
                    }
                } else {
                    console.warn(`⚠️ Door element ${doorId} not found in SVG`);
                }
            });
            
            if (closestDoor) {
                console.log(`✅ Closest door: ${closestDoor} (${minDistance.toFixed(2)}m away)`);
            }
            
            return closestDoor || doorList[0]; // Fallback to first door if calculation fails
        }
```

## What This Does:

1. **findClosestDoor()** - Calculates the geographic distance from the user's position to each door's center point and returns the ID of the closest door
2. **Updated room handler** - Now calls findClosestDoor() instead of always using the first door in the list
3. **Console logging** - Shows distances to each door and which door was selected for debugging

The system will now intelligently choose the nearest door when a room has multiple entrances! 🚪📏
